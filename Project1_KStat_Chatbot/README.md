# Project1: K-Stat AI 챗봇 개발

본 프로젝트는 **무역통계 플랫폼 K-Stat** 사용자들이 보다 쉽고 빠르게 정보를 찾을 수 있도록,  
**자연어 기반 챗봇**을 개발한 팀 프로젝트입니다.

## 주요 기능

- HS CODE 검색: GPT API와 분류 기준에 기반하여 사용자 질문에 적절한 품목 코드 추천  
- 무역통계 메뉴 안내: 사용자의 질의 의도에 맞는 K-Stat 내 통계 조회 경로 안내  
- 무역용어 설명: 초보 수출입 사용자를 위한 용어 풀이 기능
- FAQ 안내: 사이트 이용자가 자주 묻는 질문을 정리한 '무역통계 쉽게 따라하기 매뉴얼' PDF 연결 기능

## 사용 기술

- **Back-end**: Java 21, Spring Boot  
- **Database**: MySQL  
- **Front-end**: HTML, CSS, JavaScript  
- **AI/NLP**: OpenAI GPT API, Prompt Engineering

## 기여 내용 (본인)

- 전체 기획 및 시나리오 설계  
- HS CODE 분류 체계에 기반한 Prompt 구조화 및 실험  
- QA용 자연어 질문-응답 데이터 수집 및 정제  
- 챗봇 응답 문장 템플릿 설계 및 테스트

## 참고 사항

> 본 프로젝트는 5인 팀으로 협업하여 진행되었으며, 기획 및 프론트엔드, AI 설계 파트를 주도적으로 담당했습니다.  
> 향후 추가 개발 예정인 2차 프로젝트의 기반이 되는 챗봇 MVP를 구현하였습니다.

## 향후 계획 (2차 프로젝트)

- **HS CODE 기능 전체 97류 확장 (현재 33류만 구현됨)**  
- **Text-to-SQL 기반 무역통계 자동 조회 기능 추가**  
- 자체 웹페이지에 챗봇을 탑재하고 시연 예정  
- 본인은 **Text-to-SQL 개발, 프론트 구현, 기획 총괄** 역할을 맡고 있습니다.
