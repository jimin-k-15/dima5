# dima5

본 저장소는 제5기 디지털 마스터 과정 중 학습한 실습 예제 및 팀 프로젝트 소스코드를 포함하고 있습니다.  
Java 기반 백엔드 개발, 데이터베이스, 프론트엔드, Ajax, JDBC 등의 실습 결과와 함께,  
K-Stat 플랫폼을 위한 AI 챗봇 개발 프로젝트도 포함되어 있습니다.

## 폴더 구조

- `Test_Backend`: Spring 기반 CRUD, 로그인/회원가입 구현  
- `Test_DB`: SQL 및 DB 실습 코드  
- `Test_Frontend`: HTML/CSS/JavaScript 기반 프론트엔드 예제  
- `Test_JDBC`: Java-JDBC 연동 실습 코드  
- `Test_Java`: Java 기초 문법 및 객체지향 프로그래밍 실습 예제  
- `Test_jQuery`: jQuery 기반 UI 요소 조작 및 Ajax 실습  
- `Project1_KStat_Chatbot`: **1차 팀 프로젝트**  
  - 무역통계 플랫폼 K-Stat을 위한 AI 챗봇 개발 프로젝트입니다.  
  - GPT API 및 자연어 처리 기반 HS CODE 검색 기능, 통계 메뉴 경로 안내, 무역용어 설명 기능을 구현했습니다.  
  - **본인은 기획 및 프롬프트 설계, 데이터 정제 및 QA 작성에 주도적으로 참여했습니다.**

## 기술 스택

- Java 21, Spring Boot  
- MySQL, JDBC  
- HTML, CSS, JavaScript  
- jQuery, Ajax  
- OpenAI GPT API

## 예정 업데이트

- 2차 프로젝트에서는 HS CODE 기능을 **33류 → 97류 전체**로 확장하고,  
  **Text-to-SQL 기반 무역통계 조회 기능**을 추가할 예정입니다.  
- 완성된 챗봇은 자체 제작한 웹페이지에 탑재하여 시연할 계획입니다.  
- 본인은 **Text-to-SQL 개발**, **프론트 구현**, **기획**을 맡고 있습니다.

## 참고 사항

> 해당 저장소는 개인 실습 및 팀 프로젝트 기록용이며, `Project1_KStat_Chatbot` 디렉터리의 코드는 팀원들과의 협업 결과물입니다.  
> 본인은 기획, 시나리오 설계, 프롬프트 개발, 자연어 처리, 챗봇 QA 데이터 구축 파트에 주로 참여했습니다.
